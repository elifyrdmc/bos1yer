# Istanbul district boundary data

Boundary geometries are derived from the HDX COD-AB-TUR administrative-boundary dataset, distributed through `ttezer/turkiye-harita-verisi` (snapshot 2025-12-24). The repository identifies the data as CC BY-IGO; source and license details: https://github.com/ttezer/turkiye-harita-verisi/blob/master/DATA-LICENSE.md

Source data: OCHA / Humanitarian Data Exchange, COD-AB-TUR. These simplified boundaries are for visual district highlighting and are not legal, cadastral, or navigation boundaries.
